# Pita Pucuk Rebung

Deretan segitiga bergantian `gonjong` dan `kunyit`, terinspirasi motif pucuk rebung pada songket Minang. Tinggi 24px, jarak antar puncak 24px.

Pakai sebagai pembatas di bagian atas atau bawah halaman, sertifikat, dan layar "Level lulus!". Maksimal satu pita per layar. Jangan dipakai di belakang teks.

Di kode: komponen `RebungBand` (`apps/web/src/site/AboutName.tsx`) + kelas `.uk-rebung`.
